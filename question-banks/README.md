# 題庫備份

後台「匯出題庫 JSON」下載的檔案放這裡，方便版控與重複匯入。

匯入方式：後台 → **題庫管理** → 匯入題庫 JSON。
預設會勾選「匯入前先清空題庫」，也就是取代而非累加。

格式為物件陣列，`correct_index` 是正確答案在 `options` 中的索引（從 0 起算）：

```json
[
  {
    "text": "題目內容",
    "options": ["選項 A", "選項 B", "選項 C", "選項 D"],
    "correct_index": 2
  }
]
```

> 根目錄的 `questions.json` 是瀏覽器下載的預設落點，已被 `.gitignore` 忽略；
> 要保留的題庫請改名後移到這個資料夾。
